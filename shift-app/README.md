# シフト管理アプリ
## 概要
従業員がシフト希望を提出し、管理者がその希望を確認・確定できるシフト管理アプリです。
一般ユーザーと管理者で権限を分け、それぞれ利用できる機能を分けています。
## 作成した目的
学習のためにWebアプリケーションを開発したいと考えていた際、現在勤務しているアルバイト先ではシフト管理が紙媒体で行われていることに気付きました。

一方で、以前勤務していた職場ではオンライン上でシフトを確認できるシステムが導入されており、利便性の高さを実感していました。

そこで、実際の業務で利用されるシフト管理システムを参考にしながら、利用者の役に立つ実用的なアプリケーションを作成したいと考え、本アプリを開発しました。

また、FlaskやSQLiteを用いたWebアプリケーション開発、ユーザー認証、権限管理、データベース操作の学習を目的としています。
## 使用技術
Python,Flask,SQLite,HTML,CSS,JavaScript,Git / GitHub
## 主な機能
一般ユーザー機能
・ユーザー登録
・ログイン/ログアウト
・シフト希望の登録
・シフト希望の編集
・自分の確定シフトの確認
管理者機能
・全従業員のシフト希望一覧の確認
・シフト希望の確定
・確定シフト一覧の確認
・確定シフトの取り消し
その他
・ユーザーと管理者の権限管理
・確定済みシフトの重複登録防止
・確定済みシフトの管理者画面からの自動非表示
## 工夫した点
ユーザーと管理者で利用できる機能を分離

一般ユーザーと管理者で権限を分け、一般ユーザーは自分のシフト管理のみ、管理者は全従業員のシフト確認や確定処理を行えるようにしました。

重複登録を防止

管理者が同じシフトを複数回確定してしまわないよう、確定前にデータベースを確認し、既に存在するシフトは登録できないようにしました。

管理者の作業負担を軽減

確定済みのシフトは管理者ページから自動的に非表示になるようにしました。これにより、管理者は未確定のシフトのみを確認でき、作業効率の向上を図っています。

実際の業務を意識した開発

現在勤務しているアルバイト先のシフト管理方法を参考にしながら、実際の利用シーンを想定して開発を行いました。機能追加の際も「利用者にとって使いやすいか」を意識しながら改善を進めました。
## 苦労した点
ユーザー認証と権限管理

ログイン機能の実装では、セッション管理やユーザー情報の取得方法の理解に苦労しました。また、一般ユーザーと管理者で利用できる機能を分けるため、権限管理の実装にも時間を要しました。

データベース設計の変更

開発途中で勤務終了時間を追加することになり、データベースのテーブル構造や関連する処理の修正が必要になりました。機能を追加する際には、データベースだけでなく登録・編集・表示など複数箇所を修正する必要があることを学びました。

シフト確定機能の実装

シフトを確定する機能では、同じシフトが複数回登録されてしまう問題が発生しました。そのため、登録前にデータベースを確認し、重複したデータを保存しない仕組みを実装しました。

エラーの調査と解決

開発中にはデータベース関連のエラーやテンプレートエラーが発生しました。エラーメッセージを確認しながら原因を特定し、一つずつ修正することで問題解決能力を身につけることができました。
## 今後の改善点
管理者向けの検索・絞り込み機能

利用者が増えた場合、管理者がシフト希望を確認しづらくなることが考えられます。そのため、日付やユーザー名でシフトを絞り込める機能を追加し、管理者が目的のシフトを見つけやすくしたいと考えています。

カレンダー形式での表示

現在はシフトを一覧形式で表示していますが、カレンダー形式で表示することで、月全体のシフト状況をより直感的に把握できるようにしたいと考えています。

デザインの改善

現在は機能実装を優先しているため、デザイン面はシンプルな構成となっています。今後はレイアウトや配色を改善し、より見やすく使いやすいUIを目指したいと考えています。

アプリの公開

現在はローカル環境でのみ動作するため、今後はクラウドサービスへデプロイし、インターネット上から利用できるようにしたいと考えています。
## 起動方法

git clone <リポジトリURL>
2. プロジェクトフォルダへ移動
cd shift-app
3. 必要なライブラリをインストール
pip install flask werkzeug
4. アプリケーションを起動
python app.py
5. ブラウザでアクセス
